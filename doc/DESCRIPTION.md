Dashboard for A. O. Smith iCOMM water heaters, built on the unofficial py-aosmith API.

- Shows hot water availability, setpoint, mode and energy use
- Change setpoint (warns above 120 F) and mode, including vacation
- Pick which water heater when you have several
- Protected by YunoHost single sign-on; the iCOMM login can be saved on the server so it reconnects after a restart

Not affiliated with A. O. Smith. The unofficial API may stop working without notice.
